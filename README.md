# Website-assignment-HTML-and-CSS
A website made with HTML and CSS for a university assignment

The Assignment was to make a website on four pages with basic tags and css. I may have gotten a bit overboard...
This was a "Approved"/ "Not Approved" assignment with no grading after all.
This website is made with no AI, however the images are generated with AI. 
As you'll see, it's written with both Norwegian and English names for the classes and the id's. 
Why?? Idk, I just sometimes do that I guess ¯\_(ツ)_/¯

I tried doing the website as responsive as possible, and tested out different ways of centering the content/products cards. 

I still have a lot to learn, and I know there are 1000 different ways for me to do this better. 
As for now I hope you enjoy my assignment :)
